# Instrucciones para Codex

Antes de modificar el proyecto, lee `directivas/directivas.md` y las directivas de arquitectura, convenciones, seguridad, infraestructura y roadmap aplicables al cambio. Usa el README para reproducir las verificaciones y actualiza la documentación cuando cambie una decisión técnica.

Para cambios de Next.js, consulta la documentación de la versión instalada en `node_modules/next/dist/docs/`.
