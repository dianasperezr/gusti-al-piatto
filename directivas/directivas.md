# Directivas generales

- Mantén un monolito modular. Implementa solo el alcance acordado para cada etapa.
- Reutiliza componentes y lógica existentes. Añade dependencias cuando resuelvan una necesidad concreta.
- Usa TypeScript estricto y valida entradas externas con Zod en el servidor.
- Ejecuta las verificaciones descritas en el README antes de entregar cambios y documenta las decisiones relevantes.
